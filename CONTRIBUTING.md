# Contributing

Found a bug or have a suggestion? Please let us know by opening an issue in this repository.

When filing an issue, include:

- A short description of the problem or suggestion
- Steps to reproduce (if applicable)
- Expected vs actual behaviour
- Any error messages, logs, or environment details (OS, Node/.NET/etc. version)

Pull requests are welcome — if you can fix it faster than we can, please submit a PR with a clear description and tests where appropriate.
